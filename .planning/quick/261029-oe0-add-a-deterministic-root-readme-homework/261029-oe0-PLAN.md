## Locked design (approved — do not revisit)

1. One new `scripts/gen_readme.py` follows the `scripts/check_metadata.py` style: the
   `#!/usr/bin/env -S uv run --script` shebang, a PEP 723 header, and
   `sys.path.insert(0, str(Path(__file__).resolve().parent.parent))`.
2. CLI is `--dir PATH` (root override) and `--check`; no positional arguments.
3. Default mode rewrites only the bytes between `&lt;!-- BEGIN GENERATED: homeworks --&gt;` and
   `&lt;!-- END GENERATED --&gt;` in `README.md` (`&lt;` and `&gt;` are XML entities for the literal
   angle brackets, so the marker text is written verbatim). Everything outside the region is
   untouched.
4. `--check` computes the expected region, writes nothing, exits 0 when identical and 1 when
   drifted with one line naming the command to run.
5. Exit 2 is reserved for usage and environment errors: an absent or unreadable README, zero or
   duplicate begin markers, a missing end marker, an end marker before the begin marker, and an
   unresolvable root.
6. Data comes from every `homeworks/*/homework.yaml`, loaded through
   `validate_homework_text(text, root=root, homework_id=hw_id)`. A validation failure is a content
   error (exit 1) naming the homework, and no document that fails the contract is ever rendered.
7. The table has six columns `ID | Project | Board | Framework | Status | Report`, one row per
   homework, sorted by directory name. `Project` is a link to `homeworks/{id}/`. `Report` is
   `[report](homeworks/{id}/{report.path})` when the report block carries a non-empty path,
   otherwise the literal `none`. Cell text escapes the table separators.
8. Empty or absent `homeworks/` renders exactly `No homework assignments published yet.` inside the
   region.
9. Determinism is a hard requirement: no clock, no git remote, no environment-dependent output, and
   writes go through a temporary file in the same directory plus `os.replace`.
10. No `generated.manifest`, no template under `templates/`, no `--json`, no new third-party
    dependency beyond the existing PyYAML and jsonschema pins.
11. Exactly one check-only `repo: local` pre-commit hook. No new workflow file and no new workflow
    step; the CI `meta` job already runs `pre-commit run --all-files`.
12. The README is rewritten as a full English repository guide with the generated table under
    `## Homeworks`. `AGENTS.md` gains one `[MUST] [ENFORCED: pre-commit]` rule and one routing row;
    the `course-index` skill's status list and README source-of-truth sentence are corrected.
