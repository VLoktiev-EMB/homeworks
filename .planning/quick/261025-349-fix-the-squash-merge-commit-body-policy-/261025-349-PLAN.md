<objective>
Pin GitHub's squash-merge commit title and message in the committed repository policy, record why in a MADR, apply the setting to live GitHub, and prove the committed policy, live state and repository gates all agree.

Purpose: GitHub's `COMMIT_MESSAGES` default composed the squash body from every branch commit subject, which leaked a `[ci skip]` ship note into `c904062` and silently suppressed the `security` push workflow on `main`. The fix is forward-only because AGENTS.md forbids rewriting published history.

Output: two new keys in `policy/repository.json`, ADR 0011, the decisions index row, and convergence evidence from `--apply` then `--check`.

Scope note: API-coverage, assumption-delta and schema-push planner contributions do not apply. This is a two-key policy change with no phase scope, no external API integration and no ORM schema.
</objective>
