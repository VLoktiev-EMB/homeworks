<objective>
Create the report checker's skeleton end to end: the stdlib-only `scripts/report/` package, the
literal vocabulary, a fence-aware Markdown structure parser, the rule record shape, and a
standalone `scripts/check_report.py` mirroring `check_metadata.py`. Per D-01, that standalone
checker owns the report contract while `check_metadata.py` keeps the metadata and provenance
contract only. Per D-03, the parser is a structural ATX-heading and pipe-table parser with fence
tracking: no Markdown AST dependency is added and no `markdownlint` custom rule is written.
The tracer proves one rule family — the ten numbered headings — through the real CLI, real YAML,
a temp fixture root, and the real exit-code contract. Then the structure rules are completed and
the status gate is added.

Purpose: every later rule family composes into this engine, and every later plan asserts rule
ids and exit codes that this plan freezes.

Output: a working `uv run scripts/check_report.py` that reports `RPT-0xx`/`RPT-1xx` records.
The real tree legitimately fails (`### Next Steps` is absent) until plan 10-06 retrofits it;
that failure is expected and must not be "fixed" by weakening a rule.
</objective>
