<objective>
Close CR-03 of gap G-10-1: `report.path` is untrusted repository content, so the checker must never join, stat or read an absolute or escaping path.

`_validate_directory` in `scripts/check_report.py` computes `report_path = directory / report_path_value` and then calls `is_symlink()`, `is_file()` and `read_regular_text` on it. `pathlib` discards the base for an absolute value, so `Path('/dir') / '/etc/passwd'` is `/etc/passwd`; a relative `..` sequence walks out of the homework directory; and `homework.yaml` is untrusted, while the checker deliberately does not apply the JSON Schema (D-02). The phase already contains the right posture twice: `scripts/report/contract.py` `resolve_artifact` rejects absolute and lexically escaping targets and proves realpath containment (D-13), and `scripts/new_homework` `_component_conflict` walks every component with `lstat` and refuses a symlink on any prefix. The declared report path bypasses both.

Purpose: a hostile `homework.yaml` becomes an `RPT-001` content record at exit 1, and the checker never reads outside the homework directory.
Output: a containment helper in the one module that owns file I/O, regression tests for absolute, `..`, intermediate-symlink and realpath cases, the accepted nested-path case, and the contract-level hostile-document proof.
</objective>

<flagged_assumptions>
Containment is enforced against the homework directory, not the repository root. The schema's `report.path` pattern already forbids an absolute path and a `..` segment, and a report belongs to its homework directory; a path that stays inside the repository but leaves the homework directory is still refused. This is stricter than "inside the repository" and matches the report's ownership.

The final component keeps its existing classification: a symlink is `RPT-002`, an absent file is `RPT-002`. The parent realpath check is deliberately applied to `candidate.parent` only, so it cannot reclassify a final symlink and break the shipped `LifecycleTests` case.

`report.path` values with a backslash are not treated as traversal here. On POSIX a backslash is an ordinary filename character; the JSON Schema rejects it separately for documents that go through `check_metadata.py`. This plan does not add a second schema check to the report checker, because D-02 keeps that boundary.
</flagged_assumptions>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `homework.yaml` -> `report.path` join | Untrusted metadata chooses which file the checker opens. |
| declared path -> filesystem | Absolute, relative and symlinked paths can redirect a read outside the homework directory. |
| hostile content -> CLI output | A refusal must be a record at exit 1, with no traceback and no absolute host path echoed. |
