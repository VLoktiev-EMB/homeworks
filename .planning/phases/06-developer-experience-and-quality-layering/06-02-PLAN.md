## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compile command → clangd driver execution | `--query-driver` decides which binaries clangd may execute to extract system includes |
| generator mapping → committed workspace JSON | A mapping value is written verbatim into a generated file readers may trust |
| editor → filesystem | Settings decide which language server runs and whether cpptools also runs |
