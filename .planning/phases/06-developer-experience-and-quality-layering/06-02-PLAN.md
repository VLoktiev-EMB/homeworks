(1) If `$ESP_CLANGD` is set: a non-executable or missing value is an environment failure — print the `FAIL clangd-wrapper:` line and exit 2, never fall through. (2) Otherwise, test `command -v esp-clangd >/dev/null 2>&1` in an `if` condition and only then assign from `command -v esp-clangd`; a bare `CLANGD=$(command -v esp-clangd)` returns 1 when the binary is absent and kills the script before the fallback runs. (3) Otherwise enable `shopt -s nullglob`, build an array from the glob `"$HOME"/.espressif/tools/esp-clangd/esp-*/esp-clangd/bin/clangd`, and only when the array is non-empty select the newest entry with `printf '%s\n' "${candidates[@]}" | sort -V | tail -1`. A `nullglob` array is the reason an empty match does not abort: never build candidate discovery as a bare `ls … | sort | tail` pipeline, because `ls` exits 1 on no match and `pipefail` makes the whole substitution fail. (4) If nothing resolved, print one `FAIL clangd-wrapper:` line to stderr naming the esp-clangd installation source, the two-step installation command `mkdir -p "$HOME/.local/bin" && ln -sf "$PWD/scripts/clangd-wrapper.sh" "$HOME/.local/bin/clangd-wrapper"`, and `docs/standards/vscode.md`, then exit 2.

Otherwise `PIO_PACKAGES="$PIO_BASE/packages"`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compile command → clangd driver execution | `--query-driver` decides which binaries clangd may execute to extract system includes |
| generator mapping → committed workspace JSON | A mapping value is written verbatim into a generated file readers may trust |
| editor → filesystem | Settings decide which language server runs and whether cpptools also runs |

ADR 0013 records the execution implication. |
