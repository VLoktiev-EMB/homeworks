<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hook repository → repository files | A pinned lint repository runs executable code on every commit |
| hook file scope → authored content | An over-broad exclusion silently stops linting a real file |
| hook entry → working tree | A default entry that rewrites files turns the gate into an editor |
