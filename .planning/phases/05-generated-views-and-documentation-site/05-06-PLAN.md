<objective>
Vendor the exact KaTeX 0.19.0 distribution the site needs, record its provenance and integrity in a
committed checksum ledger, and add the stdlib test that is the only thing standing between a
partial copy and a silently broken math rendering.

Purpose: D-07 requires a vendored KaTeX with its licence and a checksum test, and no CDN, so
`--strict` builds never depend on the network. RESEARCH Pitfall 4 records the trap: a missing
`extra_css` or `extra_javascript` target produces no MkDocs warning at all, so the checksum test is
the only detection mechanism.

Output: `docs/assets/vendor/katex/0.19.0/` with 24 distribution files plus the authored
`render-math.js`, `FILES.sha256`, and `scripts/tests/test_docs_pins.py`.
</objective>

**Obtain the files from the exact pinned release, in a disposable directory.** Run
`npm pack katex@0.19.0 --pack-destination <fresh temp dir>` (npm 12.x is available) or, if that
fails, `curl -sSL https://registry.npmjs.org/katex/-/katex-0.19.0.tgz -o <fresh temp dir>/katex.tgz`.
Extract with `tar -xzf` into a second fresh empty directory, and copy out only the files listed
below. The archive is untrusted data: never run anything from inside it, and pass paths as
arguments. Do not copy `katex.js`, `katex.mjs`, the `.woff`/`.ttf` font fallbacks, `katex.css`,
`contrib/**` other than `auto-render.min.js`, or the source `fonts/*.ttf`.

**Exact file set (24 distribution files).** `LICENSE`, `katex.min.css`, `katex.min.js`,
`contrib/auto-render.min.js`, and these twenty faces under `fonts/`: `KaTeX_AMS-Regular.woff2`,
`KaTeX_Caligraphic-Bold.woff2`, `KaTeX_Caligraphic-Regular.woff2`, `KaTeX_Fraktur-Bold.woff2`,
`KaTeX_Fraktur-Regular.woff2`, `KaTeX_Main-Bold.woff2`, `KaTeX_Main-BoldItalic.woff2`,
`KaTeX_Main-Italic.woff2`, `KaTeX_Main-Regular.woff2`, `KaTeX_Math-BoldItalic.woff2`,
`KaTeX_Math-Italic.woff2`, `KaTeX_SansSerif-Bold.woff2`, `KaTeX_SansSerif-Italic.woff2`,
`KaTeX_SansSerif-Regular.woff2`, `KaTeX_Script-Regular.woff2`, `KaTeX_Size1-Regular.woff2`,
`KaTeX_Size2-Regular.woff2`, `KaTeX_Size3-Regular.woff2`, `KaTeX_Size4-Regular.woff2`,
`KaTeX_Typewriter-Regular.woff2`. `.woff2`-only is sufficient for every browser that renders
Material 9 (RESEARCH assumption A5).

**The authored script.** `render-math.js` is the only non-distribution file in the tree, adapted
from the Material math reference: it subscribes to `document$`, calls `renderMathInElement(body,
{delimiters: [...]})` with `$$` (display), `$` (inline), `\(`/`\)` (inline) and `\[`/`\]`
(display). It starts with a two-line comment naming the source and the reason the subscription is
needed (Material's instant loading swaps the body).

**Ledger format.** `FILES.sha256` lists the 24 distribution files, sorted by path, in
`sha256sum -c` format: the lowercase hex digest, two spaces, then the path relative to the vendor
directory (`LICENSE`, `contrib/auto-render.min.js`, `fonts/…`, `katex.min.css`, `katex.min.js`).
`render-math.js` and `FILES.sha256` itself are deliberately not listed — one is authored, the other
cannot hash itself.

**No LFS, no ignore rule change.** `.gitattributes` routes only `.pdf`, `.step`, `.stl`, `.fzz`,
`.zip`, `.bin`, `.elf` and `.vcd` to LFS, so `.woff2` and `.js` stay normal git objects and GitHub
Pages can serve them. `.gitignore` does not exclude anything under `docs/assets/`; do not add a
rule for it.
