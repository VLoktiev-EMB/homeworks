<objective>
Create the evidence record and fill it with the free measurement ladder, then run protocol A — three short Wokwi sessions (cold, warm, repeat) — from a token the owner supplies outside the command sandbox, and end with a machine-readable handoff outcome.

Purpose: This is the measurement half of the phase. Compilation, lint and the merged-image post action consume no quota (D-03), so they are measured first and completely; only the session costs simulated minutes, and each run is bounded by `--timeout 15000`. The record is written as the runs happen, so no measurement depends on a later summary or on memory. The `**Outcome:**` line is the single fact Plan 04 reads, so a failed or blocked execution can never be mistaken for a passed scenario.

Output: `.planning/phases/07-simulation-spike/07-SPIKE-EVIDENCE.md` with the vocabulary, both protocol blocks, the free-ladder rows, the three-run table with its quota ledger, the failure branches, and `## Handoff to ADR-0014`.

Review-driven hardening (Round 1): the token verifier now distinguishes the allowed literal `dummy` from a real credential; the measurement invocation loses the un-`pipefail`-ed pipeline; the wrapper gets a deterministic materialised path; failure capture and a blocked-run resume signal are defined; and the success/failure/blocked outcome is a named field.
</objective>
