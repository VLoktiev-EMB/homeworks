<objective>
Attempt the Velxio self-host image as the role-proportional second measurement: boot, image identity, board coverage, and an honest statement of whether the pilot can compile or run there.

Purpose: The phase needs a measured comparison beyond Wokwi without spending Wokwi quota. Velxio's prebuilt container is the cheapest second real measurement (D-05), and its self-host board limit is itself evidence. The attempt is owner-run because the command sandbox cannot reach the Docker socket (D-06).

Output: the `## Velxio self-host attempt` section of `07-SPIKE-EVIDENCE.md`, with a digest, a boot measurement or a named failure, the board-list observation, and the AGPL boundary.

Tracer note: this plan has no agent-runnable tracer. Every layer it touches — the Docker daemon, the registry, the container's editor and the owner's network — is outside the command sandbox, so the boot attempt itself is the thinnest end-to-end slice and is the first task. The agent's half is the recording task that follows.
</objective>
