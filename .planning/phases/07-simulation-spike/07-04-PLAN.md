**Signal:** the phase introduces a second simulator path (Wokwi primary, Velxio fallback), so the detector reads "fallback" and "chosen" as an assumption delta.

**Question:** does the value vocabulary (`simulated` versus `measured`) still name the right noun, or should a platform-role matrix become primary?

**Decision: add alongside, do not replace.** The ADR promotes a platform-role matrix to the primary artefact for platform selection — one row per platform naming its role, its measured depth, and its `not measured` reasons. The five-label value vocabulary stays unchanged, because the labels describe the provenance of a value, not the tool that produced it; a simulator-produced value remains `simulated` and gains a platform qualifier only where more than one simulator could have produced it. Renaming `simulated` to a tool-specific word would invalidate the shipped report and pre-empt the Phase 10 report contract. The change is additive and reversible; the label vocabulary is not.
</assumption_delta_decision>
