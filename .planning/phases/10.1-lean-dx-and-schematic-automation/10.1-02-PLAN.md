# Plan 10.1-02: Schematic Automation and Visual Layout

## Goal
Upgrade the schematic workflow from a manual stub to an automated, readable DX tool. Provide automated diagram layout and routing for Wokwi `diagram.json`, generate embeddable Mermaid circuit diagrams for READMEs and reports, and format `homeworks/1_3-police-flasher/assets/diagram.json` into a clean, human-readable circuit layout.

## Tasks

### Task 1: Create `scripts/gen_schematic.py` Generator
- Build a Python utility that:
  - Reads component definitions and connections.
  - Implements clean floorplanning / layout calculation (places microcontroller, groups inputs on one side, outputs on the other, spaces parts with ample margin >= 80px).
  - Routes wires cleanly: adds Manhattan bend waypoints (`h`, `v`) so wires do not cut directly through component bodies or overlap each other.
  - Applies color standards: power (`red`), ground (`black`), signals (`green`, `blue`, `orange`, `purple`).
  - Exports a clean `diagram.json` valid for Wokwi.
  - Generates a GitHub-flavored Mermaid `flowchart LR` representing the wiring connections for inclusion in Markdown documents.

### Task 2: Upgrade `schematic` Skill & Update Mirror
- Update `.claude/skills/schematic/SKILL.md` from a stub to a full skill describing:
  - How to generate and update schematics.
  - How to embed the Mermaid diagram into README/report.
  - How to capture or preview the visual diagram in Wokwi.
- Run `uv run scripts/gen_skills.py` to keep `.agents/skills/schematic/` in sync.

### Task 3: Apply to Homework 1.3 & Verify
- Reformat `homeworks/1_3-police-flasher/assets/diagram.json` using the generator so the wiring is clean, readable, and well-routed.
- Add the Mermaid wiring diagram to `homeworks/1_3-police-flasher/README.md`.
- Verify with `wokwi-cli lint --offline homeworks/1_3-police-flasher/assets/diagram.json`.
