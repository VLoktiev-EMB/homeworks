# Plan 10.1-03: Pre-commit, CI, and GSD Ceremony Trim

## Goal
Trim remaining enterprise bureaucracy from local pre-commit hooks, CI gates, and GSD configuration. Optimize for speed, low cognitive friction, and developer enjoyment while preserving genuine engineering invariants (clean code, no hardcoded secrets, passing builds, valid schemas).

## Tasks

### Task 1: Streamline `.pre-commit-config.yaml`
- Keep essential, fast hygiene checks:
  - `clang-format` (C/C++ formatting)
  - `ruff` (Python linting)
  - `gitleaks` (staged secret prevention)
  - basic file hygiene (trailing whitespace, end of file, merge conflicts, large files)
  - core contract checks (`check_metadata.py`, `check_report.py`, `gen_views.py --check`, `gen_skills.py --check`)
- Remove `markdownlint-cli2` from the pre-commit hook surface to prevent formatting pedantry on markdown documentation.

### Task 2: Streamline `.github/workflows/ci.yml`
- Remove the strict PR title regex enforcement step in `meta` job so that pull requests are not blocked on title syntax nitpicks.
- Ensure PR secret checks only inspect the PR commit range instead of rescanning full repository history on every PR (full-history scan remains scheduled in `nightly.yml`).

### Task 3: Relax GSD Settings & Update Rulebook
- In `.planning/config.json`, set `"security_enforcement": false` and adjust settings to avoid enterprise overhead.
- Update `AGENTS.md` and related documentation to reflect the streamlined expectations.
- Run `pre-commit run --all-files` and verify lightning-fast execution.
