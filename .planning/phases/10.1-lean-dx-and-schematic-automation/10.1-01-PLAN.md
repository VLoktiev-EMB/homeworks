# Plan 10.1-01: Lean Report Verification

## Goal
Debureaucratize `scripts/check_report.py` and `scripts/report/contract.py`. Replace 1400+ lines of brittle AST table/regex checking with a clean, fast validator that verifies the engineering document's core structure (headings 1-10, frontmatter, presence of content, absence of unresolved TODOs) without failing builds on table column naming, formatting minutiae, or pseudo-enterprise trivia.

## Tasks

### Task 1: Streamline `scripts/report/contract.py` and `scripts/check_report.py`
- Retain structural validation:
  1. 10 numbered section headings exist in order (`# 1. Introduction` through `# 10. Conclusion`).
  2. Frontmatter status is valid (`complete`, `in-progress`, `placeholder`) and matches homework status.
  3. No unresolved `TODO` tokens when status != `placeholder`.
  4. Placeholder status is exempt.
- Remove pedantic AST table column verifications, strict mathematical equation parsing, commit hash syntax gates, and rigid column order requirements.
- Keep output deterministic and compatible with `--json` and CI.

### Task 2: Update and Simplify `scripts/tests/test_report.py`
- Refactor the tests to assert the streamlined contract:
  - Valid report passes.
  - Missing section heading fails with helpful diagnostic.
  - Heading out of order fails.
  - Unresolved TODO in completed report fails.
  - Placeholder report passes with minimal content.
  - Empty file fails.
- Drop brittle tests asserting exact column header names or rigid formula regexes.

### Task 3: Verification
- Run `uv run scripts/check_report.py` across all homeworks.
- Run `python3 -m unittest discover scripts/tests` and ensure all tests pass.
- Verify `pre-commit run --all-files` remains green.
