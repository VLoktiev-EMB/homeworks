## Decisions Made

- `lib/common`, `lib/port` and `lib/host` use the native representative context; `lib/arduino` and `lib/espidf` use their own framework databases. One compile command per path is a physical constraint, so the native choice is deliberate, not a wrong-command defect.
- The root fragment intentionally declares no `CompilationDatabase` directory, so each homework's own database and the `tests/` database keep nearest-ancestor precedence.
- The host compiler candidates are fixed absolute paths, never a PATH lookup, keeping the allowlist reviewable and environment-independent.
- Generated template build output is excluded both from git and from the scaffold's authored-file walk; the latter became necessary once the documented ESP-IDF database build wrote that output into the template tree.
