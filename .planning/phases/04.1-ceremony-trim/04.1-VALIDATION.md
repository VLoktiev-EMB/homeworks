## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Python `unittest` (stdlib, no config file) + PlatformIO 6.2.0 / Unity 2.6.1 for C |
| **Config file** | none for Python; `tests/platformio.ini` for the native C suite |
| **Quick run command** | `python3 -m unittest scripts.tests.test_homework_metadata scripts.tests.test_new_homework -q` |
| **Full suite command** | `python3 -m unittest discover -s scripts/tests -v && pio test -d tests -e native` |
| **Estimated runtime** | ~15 s post-trim (pre-trim: 310 tests / 75.3 s; survivors alone: 87 tests / 11.6 s; native 73 cases / 2.8 s) |

**Environment precondition:** `uv` must have a writable cache. In a read-only-cache sandbox the
surviving modules raise `Could not acquire lock … Operation not permitted` and report ~30
spurious failures. Export `UV_CACHE_DIR` to a writable path before recording any number.

---

## Sampling Rate

- **After every task commit:** Run the quick run command plus the SC5 dangling-reference grep.
- **After every plan wave:** Run the full suite command plus `pre-commit run --all-files`.
- **Before `/gsd-verify-work`:** Full suite, both smoke builds, and `uv run scripts/check_metadata.py` must be green.
- **Max feedback latency:** 15 seconds (quick), 120 seconds (full incl. ESP-IDF build).
