<objective>
Reduce `scripts/tag_homework.sh` from a 200-line five-precondition gate to the minimal script
the user chose (D-3): id-shape check, `git tag` at the origin default branch, one `git push`.

What is genuinely lost is the merged-PR gate and the "directory exists at that commit" gate —
they become review/process rules. What is kept is the property the script exists for: it never
overwrites or moves a published tag, because `git tag` refuses an existing local tag and
`git push` refuses a non-fast-forward remote tag. The script also avoids a hand-typed commit
and a hard-coded `origin/main`.

The research sketch says `set -euo pipefail`; the two existing house scripts use
`set -uo pipefail` because they aggregate failures into a status variable. This script has no
aggregation, so `set -euo pipefail` is correct here; the divergence is intentional and
recorded.

Purpose: keep the tag path deterministic without the four extra network/PR preconditions.
Output: a five-line tag script and no test module asserting the old gate.
</objective>
