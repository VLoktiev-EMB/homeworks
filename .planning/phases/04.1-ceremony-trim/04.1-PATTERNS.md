### `scripts/tag_homework.sh` (utility, one-shot command)

**Current analog:** itself, lines 1-199. **House style analog:** `scripts/review_smoke_test.sh`
(93 lines) and `scripts/new_homework` (header docstring, lines 1-54).

**House style facts to match:**

| Idiom | Where observed | Note for the rewrite |
|-------|----------------|----------------------|
| Shebang | `#!/usr/bin/env bash` (`tag_homework.sh:1`, `review_smoke_test.sh:1`) | keep `bash`, not `sh` — `[[ ]]` is used |
| Strict mode | `tag_homework.sh:33` uses `set -uo pipefail`; `review_smoke_test.sh:7` uses `set -uo pipefail` | **The house style is `set -uo pipefail`, not `set -euo pipefail`** — `-e` is deliberately absent because the script aggregates failures into `status` |
| Error channel | `echo "FAIL …: …" >&2` then `exit 1` (`tag_homework.sh:89-92`, `:106-108`, `:122-124`) | keep `FAIL <topic>: <detail>` on stderr |
| Exit codes | `0` success, `1` precondition/runtime failure, `2` usage (`tag_homework.sh:24-26`) | preserve the 2 = usage-error convention |
| Usage guard | `if [ "$#" -ne 1 ]; then echo "FAIL arguments: …" >&2; usage >&2; exit 2; fi` (`:88-92`) | the minimal form may use `${1:?usage: …}` — but that exits 1, not 2 |

**Current gate structure to delete** (`tag_homework.sh:100-183`): id shape (`:103-109`),
fetch + default-branch resolve (`:114-130`), `git cat-file -e "$base:homeworks/$id"`
(`:135-140`), local/remote tag absence (`:143-162`), merged-PR via `gh` (`:166-177`).
`TAG_HOMEWORK_SKIP_REMOTE` (`:28-31`, `:37`, `:114`, `:150`, `:166`) dies with
`test_tag_homework.py`.

**Target shape** — RESEARCH.md §"Minimal tag script" (lines 750-759):

```bash
#!/usr/bin/env bash
# tag_homework.sh <id> — tag the merged homework at the current origin default branch.
set -euo pipefail
id="${1:?usage: scripts/tag_homework.sh <id>}"
[[ "$id" =~ ^[0-9]+_[0-9]+-[a-z0-9-]+$ ]] || { echo "bad id: $id" >&2; exit 2; }
base="$(git rev-parse "origin/$(git symbolic-ref --short refs/remotes/origin/HEAD)")"
git tag "hw/$id" "$base"
git push origin "refs/tags/hw/$id"
```

**Planner note:** the research sketch says `set -euo pipefail` while the two house scripts
say `set -uo pipefail`. For a five-line script with no aggregation, `-e` is correct and the
divergence is intentional; if the planner prefers house-style uniformity, `set -uo pipefail`
plus explicit `|| exit 1` works too. Record the choice rather than leaving it implicit.
Also: the sketch uses `git symbolic-ref --short` directly, whereas the current script's
`resolve_default_branch()` (`:72-77`) uses `symbolic-ref --quiet` and strips the prefix —
the minimal form may leave an unresolved ref as an empty string, which `git rev-parse` then
rejects non-zero. That is acceptable fail-closed behaviour for a five-line script.
