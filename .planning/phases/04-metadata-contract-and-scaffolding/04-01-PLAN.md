<objective>
Create the single source of truth for homework metadata and the read-only checker that applies it: `schema/homework.schema.json` (JSON Schema 2020-12, `additionalProperties: false` at every level), the shared `scripts/metadata/contract.py` module, and `scripts/check_metadata.py` with the repository's `0/1/2` exit-code contract.

Purpose: META-01 makes the schema the machine-readable contract every later generator (Phase 5), the scaffold (04-04), the pre-commit hook (04-04) and CI (Phase 8) consume. D-12 forbids divergent validation, so this plan creates the one module both callers import.

Output: a committed schema, a shared validation module, a checker that scans `homeworks/*/` (or explicit paths) and never writes, and the schema/exit-code half of `scripts/tests/test_homework_metadata.py`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem -> checker | `homework.yaml` under `homeworks/` is untrusted input parsed by PyYAML |
| schema file -> validator | a malformed or over-permissive schema silently weakens every check |
| checker -> CI | exit codes and `--json` records are consumed by Phase 8 automation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Denial of Service | `validate_homework_text` | medium | mitigate | `yaml.safe_load` only (no arbitrary object construction); cap the input file at 64 KiB before parsing, raising `CheckError` (exit 2) — the same cap as the architecture allowlist |
| T-04-04 | Tampering | `schema/homework.schema.json` | high | mitigate | Every shape is an anchored `pattern`; the suite asserts the schema contains no `format` keyword (Pitfall P1 proved `format: uri` accepts `not a url`) |
| T-04-07 | Repudiation | checker output | medium | mitigate | Sorted paths, no timestamps, no writes; a test compares two consecutive runs byte-for-byte and asserts `git status --porcelain` is unchanged |
| T-04-08 | Information Disclosure | record rendering | low | mitigate | Print repository-relative POSIX paths only; never echo an absolute root or a configured identity |
| T-04-SC | Tampering | package installs (`uv`, pre-commit) | high | mitigate | Blocking human-verify gate (Task 1) before the first install; versions pinned to PyYAML 6.0.3 and jsonschema 4.26.0 in the PEP 723 header, and the drift test in 04-04 keeps the pre-commit declaration equal |
</threat_model>
