<objective>
Close the single failed truth in `04-VERIFICATION.md` (row 10): the id-equals-directory invariant is silently skipped when an explicit absolute positional uses a spelling that differs from the resolved root.

Purpose: `_homework_directory()` currently compares `os.path.abspath(root)` against `os.path.abspath(path)`. `resolve_root()` canonicalizes the root (`/private/tmp/...`) while an explicit absolute positional keeps the caller's spelling (`/tmp/...`), so the prefix comparison fails, the helper returns `None`, and both `validate_homework_text` and `validate_candidate` treat the mismatch check as "not applicable". On this machine `$TMPDIR` is `/tmp/...`, so this is an ordinary invocation, not an exotic one. The pre-04-08 `resolve()`-based helper handled the spelling case; `d65619f` traded it for the symlinked-base case instead of covering both. The repair must cover both: reconcile only the ancestor prefix before `homeworks`, keep `homeworks` and below lexical.

Output: a spelling-independent `_homework_directory`, three regression tests (differing-spelling mismatch, matching-id control, symlinked base under a differing spelling) driven through the real CLI, and a strengthened WR-08 Cyrillic allowlist test.

Reversibility: this is a two-way, local change — one function rewrite plus tests in two already-tracked files. No `checkpoint:decision` is needed; a single revert restores the prior helper. Explicitly out of scope: the accepted TOCTOU debt (T-04-28, `_write_all`), the `templates/board-profile/profile.yaml` consumer gap (WR-03), and every truth already verified (rows 1-9, 11-59).
</objective>
