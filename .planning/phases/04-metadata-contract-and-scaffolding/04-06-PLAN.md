<objective>
Close the symlink-containment gap (CR-01) in `scripts/new_homework` and pin it with regression tests, so no scaffold write can land outside `homeworks/` or through a symlinked target directory.

Purpose: the scaffold is the only supported path to a new homework directory (AGENTS.md, D-18/D-19). Today an intermediate directory symlink writes `src/main.cpp` outside `homeworks/` with exit 0, and a symlink at `homeworks/<id>` is silently followed, so the published-homework safety contract (D-20, D-24) is false.
Output: a component-level `lstat` classification, a target-directory symlink refusal, three new regression tests, and an updated module contract docstring.
</objective>

    Harden `scripts/new_homework` so a symlink or a non-directory on any target component is refused without traversal.

    Add `import stat` to the stdlib imports. Add a module-level helper `_component_conflict(base, relative)` that returns either `None` or a `(status, reason)` tuple. It walks `relative.parts` from `base` with `os.lstat` at each step, catching `FileNotFoundError` to return `None` and converting any other `OSError` into `CheckError` naming the inspected path. On the final component, `stat.S_ISLNK` returns `("CONFLICT", "target is a symlink; refusing to follow or overwrite it")`. On an earlier component, `stat.S_ISLNK` returns `("CONFLICT", "intermediate path homeworks/<parts> is a symlink; refusing to follow it")`, and a non-directory mode returns `("CONFLICT", "intermediate path homeworks/<parts> exists and is not a directory")`. Build the reported path as `Path("homeworks")` joined with the consumed parts, rendered with `as_posix()`.

    Change `_classify` to accept `(base, target, data)`. Its first statement computes `relative = target.relative_to(base)`, calls `_component_conflict(base, relative)`, and returns that tuple when it is not `None`. Only after a clean walk may it call `target.exists()`, `target.is_file()` or `target.read_bytes()`; the existing final-symlink branch becomes unreachable and is removed. Keep the existing CREATE, UNCHANGED and remaining-CONFLICT reasons byte-identical.

    Change `_contained_target` to stop resolving the target directory before the symlink decision. Set `base = root / "homeworks"` and `target = base / homework_id`. Use `os.lstat(target)`; `FileNotFoundError` means the target is absent. When the mode is a symlink, raise `CheckError` with the exact message `target homeworks/<id> is a symlink; refusing to follow it`; when it exists and is not a directory, keep the existing `homeworks/<id> exists and is not a directory` error. Keep the `target.resolve()` plus `relative_to(base.resolve())` containment proof as defense in depth, but return the unresolved `target`, never the resolved path.

    In `_build_plan`, derive `base = target_dir.parent` and pass it to every `_classify` call as `_classify(base, target_dir / relative, data)`; `payloads` keeps the same key and value shape. Do not change `validate_candidate` usage, the placeholder map, the emit format or the write phase.

    Update the module docstring's exit-code block and its D-20 paragraph: exit 2 now includes a symlink at `homeworks/<id>`; CONFLICT now includes a symlink at any intermediate or final candidate component and a non-directory intermediate component, and such a record names the offending path.
