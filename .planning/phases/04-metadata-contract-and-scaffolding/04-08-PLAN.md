<objective>
Close the last carried-forward containment gap in Phase 4: a symlink at `homeworks/` itself is followed, so the scaffold exits 0 and writes every file outside the repository root, while the same condition silently disables the `id`-equals-directory invariant in `_homework_directory`.

Purpose: the 04-06 plan's own done criterion is that no write can land outside `homeworks/` or through a symlinked directory. That is true for every component from `homeworks/<id>` downward and false for the base one level higher, so the published-homework safety contract (D-20, D-24) is still incomplete. `04-VERIFICATION.md` records two deterministic reproductions, both re-confirmed before this plan was written: the real run wrote eight files under the symlink target with exit 0, and a mismatched `id` passed the checker with exit 0 under the symlinked base while the same tree under a real `homeworks/` exited 1.

Output: a `homeworks`-base `lstat` and resolved-base equality check in `scripts/new_homework`, a lexical containing-directory derivation in `scripts/metadata/contract.py`, two new regression tests, and an updated exit-code docstring.
</objective>
