<objective>
Build the thinnest end-to-end slice of the phase: one committed shared config, five shared
libraries with manifests and `extern "C"` headers, the reference project
`homeworks/0_0-toolchain-smoke/` wired with `lib_deps = <name>=symlink://../../lib/<name>`,
and a green native build. A second step adds the SCons hook `scripts/pio/compiledb.py`
plus its data-level test, so `compile_commands.json` proves that the shared sources take
part in compilation.

Purpose: prove that `symlink://` resolution and the library manifests work before the
phase spends roughly 1.5 GB downloading `espressif32` 8.0.0 (D-19). This is the cheapest
way to separate a configuration defect from a toolchain defect.

Output: `platformio.shared.ini` (D-01, D-04), five `library.json` manifests (D-09, D-12),
three native libraries `common`/`port`/`host`, two framework-real adapters
`arduino`/`espidf` (D-11), `homeworks/0_0-toolchain-smoke/` (D-06, D-07, D-08),
`scripts/pio/compiledb.py` (D-17) and `scripts/tests/test_pio_scripts.py`.
