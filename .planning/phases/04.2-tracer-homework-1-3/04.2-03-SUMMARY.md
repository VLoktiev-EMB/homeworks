## Accomplishments

- Authored `assets/diagram.json` as the wiring source of truth: the ESP32-S3-DevKitC-1 with
  `flashSize: "16"`, `psramType: "octal"`, and `psramSize: "8"`, followed by `r1`, `led1`,
  `led2`, `r2`, `led3`, and the MODE button. The D-03 half-bridge is wired exactly as
  specified: GPIO4 to `r1:1`, `r1:2` to `led1:A`, `led1:C` to GND, `led2:A` to 3V3, and
  `led2:C` back to `r1:2`, so the shared node X is neither ground nor tied to an independent
  GPIO. The third LED runs from GPIO6 through `r2`, and the button from GPIO7 to GND.
- Linted the diagram offline without a token: `wokwi-cli 0.28.1` exits 0 with only the
  informational `unsupported-part` note for the board type. No `invalid-pin` or connection
  error was raised.
- Added `merge_firmware.py`, the only new executable code this phase. It imports only
  `join` from `os.path`, resolves esptool through
  `env.PioPlatform().get_package_dir("tool-esptool")`, builds the image list from
  `FLASH_EXTRA_IMAGES` plus `$ESP32_APP_OFFSET`, quotes every path argument, and writes only
  `$BUILD_DIR/firmware.merged.bin`. The target build reports `SUCCESS` in 8.32 s and the merge
  reports `Wrote 0x5da00 bytes` (383,488 bytes on disk).
- Repeated the inherited `pre:../../scripts/pio/compiledb.py` beside the new
  `post:merge_firmware.py`, so `extends` does not silently drop the compilation database; the
  `compiledb` target still writes `compile_commands.json` at the project root.
- Authored `scenario.yaml` to wait for the firmware's own `pattern ready` handshake, delay
  100 ms, and expect `esp` pin `4` high. The delay is deliberately inside alternating frame 0
  (400 ms at speed index 0); frame 1 drives GPIO4 LOW.
- Attempted the run once from the repository root with the exact README command and observed
  the expected `Missing WOKWI_CLI_TOKEN` error. No token was written anywhere, and
  `simulation.status` stayed `pending`.
- Confirmed no generated artifact is tracked: `git ls-files` returns nothing for the
  homework's `.pio/**`, `*.bin`, or `*.elf`, and the native suite still reports 38 of 38
  cases passing.

## Decisions Made

- **GPIO6 is the third LED.** The research sketch used GPIO5, but the composition root places
  `LED_C_PIN` on GPIO6 and reserves GPIO5 for the alternative three-LED profile. The plan's
  explicit wiring won.
- **The merge hook stays project-local.** Promoting it to `scripts/pio/` would make it shared
  code before the Phase 7 simulation ADR decides whether Wokwi remains the tool. F-09 records
  it as a Phase 7/8 reuse candidate instead.
- **A 100 ms delay, not 500 ms.** The scenario must land inside alternating frame 0, whose
  400 ms hold at speed index 0 is the only window where GPIO4 is high.
- **Lint is the verified simulation result.** The missing token is recorded friction, not a
  task failure; `simulation.status` stays `pending` so no report can mistake lint for
  execution.
- **REQUIREMENTS.md marking is deferred.** Both IDs in this plan's frontmatter are also
  declared by plan 02, so the shared-ID gate keeps them open until every declaring plan in the
  phase has a summary.
