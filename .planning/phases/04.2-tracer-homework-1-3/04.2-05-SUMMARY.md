- **No fabricated measurement.** With no bench reading and no serial log, every bench quantity
  is `not measured` with the fixed reason, and the report states that no measured values were
  captured. This is the plan's autonomous contract and the phase's core value.
- **The implementation commit stays `6a60426`.** `src/main.cpp` and `controller.c` did not
  change in this plan, so refreshing the hash would have broken the agreement between the
  metadata table and the ledger for no reason. The verify asserts the agreement.
- **The build timing is reported honestly.** The re-verified incremental build took 0.54 s and
  the phase's cold build took 8.21 s; the report gives both rather than presenting the fast
  incremental number as a cold build.
- **D-09 is recorded as a manual review.** The appendix states the checklist result and that the
  user's confirmation lands in the pull request before merge (plan 07); it does not claim a
  completed user sign-off.
- **The two half-bridge limits are verified at the logic level only.** The rows for the
  high-impedance off state and the SOLID precedence are `verified` because the native suite
  pins the controller behaviour; the hardware observations they do not cover stay `not
  measured` or `pending` in the ledger.
