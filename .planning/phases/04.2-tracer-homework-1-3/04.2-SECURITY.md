## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Assignment text to repository | Access-restricted course material must never cross into a public file. | Prose, institution identity, LMS URL |
| Scaffold argument to filesystem | The homework ID and template name determine every write path. | Path strings |
| Developer environment to repository | Secrets and private identifiers must not be captured in any staged file. | Tokens, home paths, identities |
| Repository to CI runner | Third-party actions and package installs execute with repository contents. | Source, pinned dependencies |
| Firmware build to Wokwi | The merged image is loaded by a simulator when a token is present. | Binary image |
