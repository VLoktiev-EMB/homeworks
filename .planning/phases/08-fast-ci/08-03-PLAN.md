<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fork pull request → token-bearing job | A fork controls the diff and the workflow run, but not the label or the secret |
| pull-request label → job execution | A maintainer-applied label is the only manual switch |
| downloaded release asset → runner | wokwi-cli arrives over the network with no vendor checksum |
| scenario output → artifact | The scenario stdout and serial log leave the runner |
| matrix value → shell | `matrix.project` and `matrix.env` are contributor-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-8-11 | Information Disclosure | `simulate` job | high | mitigate | The job-level `if` requires the head repository to equal `github.repository`, so a fork never receives the secret; the token is read from `secrets` only into a job-level `env` and is never echoed (D-9, Pitfall 11). |
| T-8-12 | Elevation / Tampering | `simulate` build and scenario steps | high | mitigate | `matrix.project` and `matrix.env` enter through `env:` and are quoted as `"$PROJECT"` and `"$ENV_NAME"`; `--scenario` and `--diagram-file` stay relative to the project directory, as the path test proves (Pitfall 10). |
| T-8-13 | Tampering | wokwi-cli download | high | mitigate | The binary is pinned to 0.28.1 and checked against the recorded SHA-256 before `install`; the official action's unversioned download is not used (D-10, Pitfall 12). |
| T-8-14 | Denial of Service | Wokwi free-tier quota | medium | mitigate | Three controls bound spend: the maintainer label, `max-parallel: 2`, and the 10-minute job timeout with a 15-second scenario timeout; nightly never simulates. |
| T-8-15 | Information Disclosure | uploaded artifacts | medium | mitigate | Only the serial log, the scenario stdout and the quota JSON are uploaded, with 7-day retention; the token is passed as an environment variable and never written by the scenario step. |
| T-8-16 | Repudiation | `python-tests`, `static-analysis` | medium | mitigate | Both jobs are named in `gate.needs`, so a suite or clang-tidy failure blocks the merge instead of disappearing from the check surface. |
| T-8-SC | Tampering | pip installs and the wokwi binary | high | mitigate | Exact pins (`platformio==6.2.0`, `pre-commit==4.7.0`, `uv==0.13.5`) and a SHA-256 check on the binary; RESEARCH §Package Legitimacy Audit records the disposition and the observed digest. No `[SLOP]` package is present. |
</threat_model>
