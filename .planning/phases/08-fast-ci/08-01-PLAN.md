<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fork or contributor branch → pull-request workflow | The diff, the PR title and every `platformio.ini` are contributor-controlled |
| GitHub expression context → shell | `${{ }}` values reach `run:` unless routed through `env:` |
| downloaded release asset → runner | gitleaks and wokwi-cli binaries arrive over the network |
| previous runs → cache | A cache entry restores into a later job |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-8-01 | Elevation / Tampering | `meta` title step | high | mitigate | `github.event.pull_request.title` enters only through `env: PR_TITLE`; the shell quotes `"$PR_TITLE"`; the regex is a literal, never built from the value (D-16). |
| T-8-02 | Elevation / Tampering | `build` steps | high | mitigate | `matrix.project` and `matrix.env` enter through `env:` and are quoted as `"$PROJECT"` and `"$ENV_NAME"`; no `${{ matrix.* }}` appears in a `run:` body (Pitfall 10). |
| T-8-03 | Information Disclosure | `meta`, `changes`, `build` | high | mitigate | Every job declares `contents: read`, none references `secrets.*`, and no workflow uses a pull-request-target trigger (D-13, Pitfall 11). |
| T-8-04 | Tampering | every `uses:` and every pip install | high | mitigate | Actions pin a commit SHA with a version comment; pip pins exact versions; the gitleaks archive and the wokwi binary are checksum-verified before execution (D-14). |
| T-8-05 | Tampering | `actions/cache` keys | medium | mitigate | Keys derive from the reviewed pin files (`.pre-commit-config.yaml`, `platformio.shared.ini`) with no broad `restore-keys`, so a near-miss never restores a foreign toolchain (D-13, D-18). |
| T-8-06 | Repudiation | `gate` aggregation | high | mitigate | The jq filter allows only `success` and `skipped`; a `failure` or `cancelled` dependency fails the job and therefore the required check (D-2). |
| T-8-SC | Tampering | pip installs and downloaded binaries | high | mitigate | Exact pins (`platformio==6.2.0`, `pre-commit==4.7.0`, `uv==0.13.5`), SHA-256 verification for gitleaks and wokwi-cli, and the RESEARCH §Package Legitimacy Audit recorded in this plan. No `[SLOP]` package is present. |
