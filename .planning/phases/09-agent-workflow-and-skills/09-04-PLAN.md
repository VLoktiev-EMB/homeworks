<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| skill → source tree | A repair edits authored code; an unbounded or broad edit destroys work |
| user input → shell | The homework id selects the project directory |
| command → reported result | A wrapper can hide a non-zero exit code |
| build output → agent | Compiler diagnostics are untrusted text and may contain misleading paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-06 | Tampering | the repair loop | high | mitigate | Two attempts per run; smallest fix; no unrelated reformat; no `git checkout --`, reset or test weakening; stop and escalate after the second failure. |
| T-09-03 | Tampering / Elevation | homework id in `pio run -d` and `pio test -d` | high | mitigate | Validate the id against the canonical pattern and pass it as one argv element, never a shell string. |
| T-09-14 | Repudiation | reported build result | medium | mitigate | Run the real `pio` commands and report their exit codes; never wrap them in a script that synthesizes a status. |
| T-09-SC | Tampering | package installs | low | accept | No package is installed; the skill invokes the already-pinned PlatformIO Core. |
</threat_model>
