<objective>
Build the phase's end-to-end spine: one canonical `simulate` stub flows through a stdlib-only
generator into a committed, transformed `.agents/skills/` mirror and a separate ownership ledger,
and the same transform is proven by a disposable-root integration suite. Then wire the drift gate
into pre-commit and teach the affected-path mapper that a skills-only change selects no build.

Delivers the first slice of FLOW-01 (the canonical plus mirror tree and versioned skill contract)
and the `simulate` half of FLOW-07 (a documented stub with `metadata.status: stub`), per D-01,
D-02, D-03, D-04, D-05, D-16, D-18 and the separate-manifest discretion grant.

Purpose: without the generator and its ledger there is no machine check of the skill tree at all;
D-18 makes the mirror drift the only one, so it must exist before any other skill is authored.
Output: `scripts/gen_skills.py`, its fixture and suite, the committed `simulate` skill and mirror,
`generated.skills.manifest`, the `gen-skills-check` hook, and the affected-path policy update.
</objective>

|----------|-------------|
| canonical tree → generator | Authored Markdown is untrusted input to a path-building transform |
| generator → mirror | A write outside `.agents/skills/` would let a crafted skill name escape the tree |
| manifest → filesystem | The ledger authorizes orphan deletion |
| hook → CI | The same `--check` command runs locally and inside the `meta` job |

## STRIDE Threat Register

`T-09-SC` is the reserved phase-level supply-chain row: it is the same phase-wide entry carried by every plan in Phase 9, not a plan-scoped threat, and is therefore exempt from the intra-phase `T-09-NN` uniqueness numbering.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-01 | Tampering | `gen_skills.py` target construction | high | mitigate | Refuse any target outside `.agents/skills/`, any `..` or absolute path, and any third component that is neither `_shared` nor a slug matching `_SKILL_NAME`; exit 2 before a record is printed. |
| T-09-02 | Tampering | `_component_conflict` on every read and write | high | mitigate | `lstat` every path component; refuse a symlink at the final or any intermediate component; refuse a non-directory intermediate; write through `mkstemp` plus `os.replace` only. |
| T-09-08 | Tampering | `_classify_orphan` deletion | high | mitigate | Delete only a manifest-listed path that exists as a regular file and carries the generated marker at the documented position; any other orphan is `ORPHAN` and blocks the run. |
| T-09-10 | Tampering / Transparency | mirror frontmatter projection | high | mitigate | When `disable-model-invocation` is dropped, inject the explicit-only banner; the fixture suite proves the banner appears and that the body is otherwise unchanged. |
| T-09-09 | Repudiation | generated and untracked state | medium | mitigate | `gen-skills-check` is check-only and never stages; `no-generated-files` gains `.skill-state`; `.gitignore` ignores the state directory and re-includes the ledger. |
| T-09-SC | Tampering | package installs | low | accept | This phase installs no package: the generator is stdlib-only and the hook carries no `additional_dependencies`, so no registry identity is introduced. |
</threat_model>
