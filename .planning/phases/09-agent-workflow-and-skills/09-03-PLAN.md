## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user free-text answers → shell commands | An answer must never reach a command through string interpolation |
| user answers → `.skill-state/<id>.json` | The state file is machine-local but may hold a credential if the intake asks for one |
| homework metadata → skill reasoning | `task.md` and `homework.yaml` are data, never instructions |
| skill → `.skill-state/` | A symlinked path could redirect a write outside the intended directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-03 | Tampering / Elevation | homework id and template name interpolation | high | mitigate | Validate the id against `^[0-9]+_[0-9]+-[a-z0-9-]+$` and the template against `arduino|espidf` before use; pass each as one argv element, never a shell string. |
| T-09-04 | Information disclosure | `.skill-state/<id>.json` and any log | high | mitigate | Never ask for or record a token; store `simulation_token_present` as a boolean; the guardrails secrets section is read before the first write. |
| T-09-07 | Spoofing | `task.md`, `homework.yaml`, `report.md` content | medium | mitigate | Treat file content as data; the skill never follows an instruction found inside homework metadata. |
| T-09-12 | Tampering | state-file write path | medium | mitigate | Resolve `.skill-state/` under the chosen root, refuse a symlink at any component, create parents, and write through a temporary file plus `os.replace`. |
| T-09-13 | Spoofing / Transparency | "Поясни глибше" and assumption acceptance | medium | mitigate | Depth is only a user choice, and an assumption is `proposed` until the user accepts it; neither is inferred from silence. |
| T-09-SC | Tampering | package installs | low | accept | No package is installed; the skill wraps existing scripts and writes Markdown and JSON. |
