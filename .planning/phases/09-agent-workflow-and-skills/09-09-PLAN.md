  read. The rejected alternative — a skill-only stop — would leave the only real homework
  without a declared rate and ask the user for a value the report already records.

- **CR-01 — a scoped, fail-closed capture exception.** D-20 locks the capture "to an ignored

  serial capture; removing persistence would contradict a locked decision. So the shared

  when a credential-shape scan of the exact bytes finds no match, and on a match it writes
  nothing and reports `capture unavailable`. The rule is stated once in
  `_shared/guardrails.md`; `hw-flash` references it and never restates it.

- **WR-01 — code and prose agree.** The snippet builds the argv with the `-e <env>` rule,
  distinguishes a missing `pio`, checks `returncode` when the monitor exits before the
  bound, applies the guardrails' scan, and performs the announced atomic write.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device -> `.skill-state/logs/<id>.log` | Untrusted device bytes cross into a persisted local file. |
