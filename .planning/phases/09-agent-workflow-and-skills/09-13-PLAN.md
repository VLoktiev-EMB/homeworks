<objective>
Close GAP 3 / WR-10 and GAP 4 / WR-11: the helper must reject an invalid duration and must
never leave `pio device monitor` running.

Two defects in one lifecycle. First, `main` validates only `args.seconds <= 0`, which is False
for NaN and infinity; the non-finite deadline then reaches `select.select`, which raises
`ValueError` or `OverflowError` — neither is `CaptureFailed` or `CheckError`, so the CLI exits
with a traceback and the documented exit 2 never happens. Second, `capture_pty`'s `finally`
closes only the master descriptor; every exception other than the explicit deadline and EOF
paths propagates with the child neither killed nor waited, leaving a busy serial port and a
`ResourceWarning`.

Purpose: make an invalid duration a usage error before any process starts, and make the child
lifecycle exception-safe on every path.
Output: finite/positive/upper-bound validation, a reaping `finally`, tests that fail on the
shipped tree, the regenerated mirror, and the recorded dispositions.

Design choice: keep the reap in `capture_pty`'s `finally` rather than catching exception
classes. Catching would hide `KeyboardInterrupt` and `MemoryError`; a `finally` reap preserves
propagation and owns the child.
</objective>
