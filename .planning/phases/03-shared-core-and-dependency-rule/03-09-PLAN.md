<objective>
Prove the two properties that the native project exists for: no target toolchain or framework can enter
the shared build, and the suite produces the same result on twenty consecutive runs. Record exactly
what the compile gate does and does not prove.

Purpose: success criteria 2, 3 and 4 of the phase are only meaningful if they are measurable. The
compile gate is the only check that catches a transitive framework dependency; the 20-run digest is the
only check that catches a suite that reads a clock or depends on ordering. Neither is implied by the
other plans, and both need the final tree, so they land last.

Output: `scripts/tests/test_native_purity.py` and `scripts/tests/test_native_determinism.py`, each
with an explicit statement of its limit.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
