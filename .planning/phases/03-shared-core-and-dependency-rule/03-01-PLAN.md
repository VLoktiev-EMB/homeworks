<objective>
Prove the whole Phase 3 architecture on one thin, production-quality path: a top-level
`tests/` PlatformIO project that builds `common`, `port` and `host` on the host, a
consumer-owned `port_time_t` contract, a framework-free `common/timing` module that accepts
time instead of reading it, a deterministic `host` fake clock, and a Unity suite that drives
the debounce helper through the fake. The remaining Phase 3 plans expand outward from this
slice.

Purpose: the three riskiest assumptions in this phase are structural — that a top-level
`tests/` project works at this depth, that `common → port` compiles and links with no target
toolchain, and that fake time can drive a real timing helper deterministically. Proving all
three in one commit on the agent's freshest context is cheaper than discovering an
architectural dead end after the four other contracts and five fakes are written.

Output: `tests/platformio.ini`, two Unity suites, `lib/port/include/port/{status,time}.h`,
`lib/common/{include/common/timing.h,src/timing.c}` and
`lib/host/{include/host/fake_time.h,src/fake_time.c}`. The Phase 2 stub headers and sources
stay untouched; plan 03-07 retires them.
</objective>

       `bool common_timer_expired(uint32_t now_ms, uint32_t deadline_ms);`
       `bool common_debounce_update(common_debounce_t *state, const port_time_t *time, bool raw_input, uint32_t stable_ms);`

       distinguish "no pending change" from "a change that began at time zero", so a second transition

       timestamp when `raw_input` differs from `candidate`, promotes the candidate to `stable` once
       `common_elapsed_ms(now, candidate_since_ms) >= stable_ms`, and returns the current `stable`
       value. Initialize with `common_debounce_t state = {0};`. Guard every pointer parameter by
       returning a safe value (`0`, `false`, or the unchanged `stable`) when it is `NULL`; do not call
       any clock or sleep function from this translation unit. In the header comment, state the expiry
       horizon precisely: the signed 32-bit difference detects at most `2^31 - 1` ms (about 24.85
       days) into the future, and a deadline farther away reads as already expired.
