<objective>
Deliver the three non-timing primitives of the shared core — a fixed-capacity ring buffer, CRC-16
helpers and hexadecimal codecs — each allocation-free, each with its own Unity suite.

Purpose: ARCH-02 asks for domain logic that never blocks and never reads a clock. These three are the
smallest set that a real homework needs (framing, checksums, debug output) and the largest set
justified by one consumer. Deferring `fixed_point`, a generic state machine and a calculations module
is a deliberate anti-speculation decision, not an omission (D-11, Pitfall C15).

Output: three header/source pairs under `lib/common/` and three additional Unity applications under
`tests/test/`.
</objective>
