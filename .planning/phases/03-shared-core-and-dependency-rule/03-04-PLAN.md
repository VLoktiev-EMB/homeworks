<objective>
Deliver the three non-timing primitives of the shared core — a fixed-capacity ring buffer, CRC-16
helpers and hexadecimal codecs — each allocation-free, each with its own Unity suite.

Purpose: ARCH-02 asks for domain logic that never blocks and never reads a clock. These three are the
smallest set that a real homework needs (framing, checksums, debug output) and the largest set
justified by one consumer. Deferring `fixed_point`, a generic state machine and a calculations module
is a deliberate anti-speculation decision, not an omission (D-11, Pitfall C15).

Output: three header/source pairs under `lib/common/` and three additional Unity applications under
`tests/test/`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller buffer -> shared primitive | Every function trusts a caller-supplied pointer and length; a capacity mistake becomes an out-of-bounds write in every consumer |
| checksum output -> report claim | A CRC value can be mistaken for a security control if the prose is loose |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07 | Tampering | ring-buffer index arithmetic | medium | mitigate | `count` is authoritative for full/empty; the wrap test reads values back in order; no arithmetic depends on `head == tail` as a sentinel |
| T-03-08 | Spoofing | CRC-16 as a trust signal | medium | mitigate | The header states initial value, polynomial and "data integrity, not authentication"; the suite pins the standard check value so the algorithm cannot be swapped silently |
| T-03-SC | Tampering | package installs | high | mitigate | This plan installs nothing; no third-party CRC or codec library is introduced (research §Don't Hand-Roll) |
</threat_model>
