<objective>
Complete the deterministic test doubles: recording GPIO, loopback I2C and SPI, and a capturing log
sink, each exposing the real contract type and each scriptable to fail.

Purpose: ARCH-03 requires deterministic test doubles, and D-07 requires one for every contract, not
only for the ones with a real adapter this phase. Fakes are what make the 20-run determinism proof in
plan 03-09 meaningful: without them, a suite that touches GPIO or logging could only run on hardware.

Output: four header/source pairs under `lib/host/` and one Unity suite that exercises normal, bounded
and forced-error paths.
</objective>
