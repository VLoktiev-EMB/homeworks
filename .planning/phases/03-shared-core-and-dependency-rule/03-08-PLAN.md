<objective>
Turn the dependency rule into a failing check: a textual `#include` scanner with a deny-by-default
allowlist, the `platformio.ini` closure rules, a public-header contract test, and a local pre-commit
hook.

Purpose: ARCH-05 requires enforcement, and research proved that the compiler cannot supply it — a
relative include from `common` into an adapter compiles and links natively. The textual checker is
therefore load-bearing: it enforces source intent, while the native build enforces transitive purity.
Both are needed, and this plan delivers the first.

Output: `scripts/check_architecture.py`, `scripts/architecture/allowlist.json`, two Python test
modules covering the checker and the header surface, and one new `repo: local` pre-commit hook.
</objective>

## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-17 | Information Disclosure | `os.walk` over `lib/**` with symlinks | high | mitigate | `followlinks=False`, every file resolved with `Path.resolve()`, containment checked against the resolved root, and a `../` include classified as a violation before any resolution; ASVS V12 |
| T-03-18 | Repudiation | empty or missing tree | high | mitigate | A missing `lib/` or a zero-file scan raises `CheckError` (exit 2), never a silent success; a real-tree test asserts the PASS lines |
| T-03-19 | Elevation of Privilege | `scripts/architecture/allowlist.json` | medium | mitigate | Empty by default, entry requires `path`, `rule` and `reason`, stale entries fail, byte cap plus schema check, exit 2 on malformed input |
| T-03-20 | Tampering | `pre-commit` hook invocation | low | mitigate | `language: system` with a fixed `entry` and no filename interpolation; `pass_filenames: false`; the checker uses list-form subprocess arguments only |
| T-03-SC | Tampering | package installs | high | mitigate | This plan installs nothing; the checker is stdlib-only and the hook reuses the already-pinned pre-commit runtime |
</threat_model>
