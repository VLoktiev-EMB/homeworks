<objective>
Discharge the Phase 2 carry-forward and retire the Phase 2 linking stubs: move the partition table to
a permanent location, refactor the tests onto permanent fixtures, retire the five stub header/source
pairs, and delete the temporary smoke project in a dedicated commit.

Purpose: the smoke project is the only copy of `default_16MB.csv` and the only project the test suite
hard-reads. Deleting it before the move breaks every ESP32 build; deleting the stubs before the real
modules exist breaks the suite. This plan is the ordered close-out that makes both removals safe, and
each task's verify matches the tree that exists at that moment.

Output: `partitions/default_16MB.csv`, a shared config pointing at it, a suite that no longer names
the smoke project, five manifests at `0.2.0`, and a `lib/` tree with no stub files.
</objective>
