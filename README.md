# Homeworks

A public GitHub monorepo for 30+ homework assignments from an embedded engineering
course. Each homework is an independent PlatformIO project that ships as a
self-contained, reproducible engineering artifact: code, tests, an academic report in
Markdown, wiring, a bill of materials, engineering calculations, and measured evidence —
all understandable and verifiable a year later.

**Status:** the first homework, [1.3 Police Flasher](homeworks/1_3-police-flasher/), is in
progress. The repository holds the shared libraries, the metadata contract, the scaffold, the
generated views, and that first homework project; the authored decision and standards
documents render directly in the repository view.

## Repository rules

All contribution and agent rules live in [AGENTS.md](AGENTS.md). It is the canonical
rulebook for humans and agents alike; `.claude/CLAUDE.md` imports it rather than
duplicating it.

## Decisions

Decisions are recorded in a one-page table at
[docs/decisions/](docs/decisions/README.md). The table is the index and the default
record; a deeper ADR file is created only when a decision needs real argumentation.
