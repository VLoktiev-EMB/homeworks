# Homeworks

This is the documentation site of one public GitHub repository: a growing set of
embedded-engineering homework projects, each built with PlatformIO and shipped with
its code, tests, report, wiring, and measured evidence.

A homework is a self-contained artifact rather than a folder of snippets — it can be
read, rebuilt, and verified long after it was written. The catalogue below is generated
from the projects' metadata, so this page and the repository index always list the same
work.

The architecture and process decisions behind the repository live in the
[decision records](decisions/README.md).
